# RUNA Digital

Landing page institucional estática, feita em HTML e CSS e pronta para publicação no GitHub Pages.

## Publicar no GitHub Pages

Nas configurações do repositório, abra **Pages**, escolha **Deploy from a branch**, selecione a branch principal e a pasta `/ (root)**. O GitHub publica o `index.html` diretamente, sem build.

## Conteúdo

- `index.html`: estrutura, textos e metadados do site.
- `styles.css`: identidade visual e layout responsivo.
- `assets/logo-runa.png`: marca usada no cabeçalho, rodapé e favicon.

O contato usa `contato@runadigital.dev.br` como destino de e-mail. Altere o endereço no link `mailto:` em `index.html` se preferir outro contato.
